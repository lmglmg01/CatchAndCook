# 담당 기능 및 구현 근거

원본 Unity 저장소는 `CTeamProject`이며 제품 설정의 이름은 `DaveTheDiver`입니다. 아래 커밋은 원본 저장소에서 확인할 수 있습니다. 동작 설명은 코드와 씬 변경 이력 기준입니다.

## 선상 상호작용과 거래

- **NPC 메뉴** — NPC에게 접근하면 대화·상점·장비 강화 메뉴를 선택할 수 있습니다. 메뉴를 열면 이동을 제한하고 닫을 때 조작과 화면 상태를 복원합니다. 잠수 지점과 시간 넘기기 기능은 씬 전환에 연결했습니다. 근거 `d613d0bc`, `e38e4e76` · `Npc/BoatNPCInteractionController.cs`, `Scene/PlayScene.cs`
- **구매와 판매** — 구매에서는 판매 여부·품절·인벤토리 수용 여부·골드를 확인합니다. 골드를 차감한 뒤 아이템 추가가 실패하면 차감액을 반환합니다. 판매에서는 보유 수량을 확인해 아이템을 회수하고, 골드 지급이 실패하면 수량을 복구합니다. 근거 `d613d0bc`, `e38e4e76` · `Item/Shop.cs`, `Item/Inventory.cs`
- **공용 UI 연동** — 거래 및 장비 강화 결과를 공용 UI에 반영하고, 유틸리티 두 칸의 장착 아이템을 관리합니다. 팀원이 구현한 장비 컨트롤러와 다이브 능력치 적용 로직에 선상 강화 UI를 연결한 범위입니다. 근거 `e38e4e76`, 팀원 커밋 `83e0fe95` · `Scene/GameplayViewConnector.cs`, `Scene/PlayScene.cs`

## 잠수 조작과 퀘스트 정산

- **조작과 HUD** — 수중 이동, 나이프·작살·총 전환, 조준과 공격 입력을 연결했습니다. 조준 중 이동을 제한하고, Collider 트리거로 범위 안의 상호작용 후보를 관리해 가장 가까운 유효 대상을 선택합니다. HUD에는 산소 비율과 경고색, 수심, 무기·탄약, 유틸리티 장착 정보를 표시합니다. 근거 `d613d0bc`, `e38e4e76` · `Hero/UnderSeaHero.cs`, `InteractObj/InteractableSensor.cs`, `Views/2.Dive/DiveCharacterView.cs`
- **귀환 처리** — 결과 화면이 열리면 입력과 산소 소모를 멈춥니다. 정상 귀환은 전체 획득물, 산소 소진 귀환은 선택한 한 종류의 보유 수량을 확정합니다. 공용 결과 화면의 확정 이벤트를 연결해 인벤토리에 추가된 획득물을 수집 퀘스트에 보고한 뒤 다음 시간대로 이동합니다. 근거 `f74d678a`, `e38e4e76` · `Scene/PlayScene.cs`
- **퀘스트 데이터와 진행** — 레벨 1~10 메인·서브 퀘스트 데이터를 구성하고 요구 레벨과 선행 퀘스트를 확인하는 해금 조건을 추가했습니다. 수집·지역 진입·조사·처치 이벤트에서 진행을 보고하도록 연결했습니다. 귀환으로 확보한 손질 생선에는 아이템 데이터에 설정된 경험치를 반영합니다. 근거 `af7b006b`, `e38e4e76` · `Quest/QuestController.cs`, `Quest/QuestAreaTrigger.cs`, `Quest/QuestFishEventBridge.cs`

## 전기 뱀장어 보스전

돌진 물기·흡입·꼬리 휩쓸기 패턴과 전투 씬·프리팹을 작업했습니다. 추상 클래스에 공통 동작을 정의하고 컨트롤러가 패턴 완료 이벤트를 받아 다음 패턴으로 진행하게 했습니다. 패턴 단계에 따라 피격 가능한 콜라이더가 달라지며, 부위별 피해는 하나의 보스 체력에 반영됩니다. 모델·애니메이션 적용과 전투 연출도 작업했습니다. 근거 `faa3b53e`, `02b3a0b6`, `40209d19` · `Boss/BossPattern.cs`, `Boss/BossPatternController.cs`, `Boss/BossBattleSession.cs`

## 저장·불러오기와 빌드 진입

- **5슬롯 저장** — 새 게임·이어하기·슬롯 삭제를 시작 메뉴에 연결했습니다. 인벤토리·장비·퀘스트 등 진행 상태를 JSON으로 직렬화합니다. 임시 파일에 먼저 기록하고 기존 파일을 백업하며 교체하도록 구성했으며, 원본 파일을 읽지 못하면 백업을 시도합니다. 근거 `ce46e343` · `SaveLoad/GameSaveService.cs`, `SaveLoad/StartSceneView.cs`
- **씬 경로와 기존 저장 호환** — 오후 보트 이름 변경에 맞춰 귀환 경로를 수정하고, 병합 후 시작 씬의 빌드 진입 순서를 복구했습니다. 야간 전환 목적지를 `Sushi 2`로 갱신하고, 저장에 남은 `Sushi`를 불러올 때 새 이름으로 매핑합니다. 기존 초밥집 진행 데이터는 공용 저장 서비스와 연동했습니다. 근거 `95116bf3`, `ce46e343`, `f36cb0af`, `4d1fae86` · `Scene/GameManager.cs`, `SaveLoad/GameSaveService.cs`, `ProjectSettings/EditorBuildSettings.asset`

## 확인 범위

스크립트 경로는 원본 저장소의 `Assets/02.Scripts/` 기준입니다. 초밥집의 손님·조리·메뉴·재고 기능은 팀원 작성 커밋으로 확인되며, 본인 기여는 야간 진입과 저장 연동입니다. 발표 시점 후속 작업은 유틸리티 사용 효과, 아이템별 무게 데이터, 일부 퀘스트 대상의 씬 배치 및 퀘스트 보상 지급입니다.
